## Open questions and limitations

This file is useful, but it is not “complete certainty.” A lot of the long-tail ecosystem still has thin public evidence. Some websites that matter most for family-community hubs were either partially inaccessible in capture, returned 405/406/502 errors, or exposed only homepage-level marketing without clean inner-page calendars. That especially affected some **BlissInvestor community pages**, some **Worldschool Atlas** pages, and several smaller niche hub sites. In those cases I normalized the directory into your target schema, preserved the best anchor URLs I had, set confidence conservatively, and marked many records `ambiguous` rather than inventing dates.

The thinnest evidence in the final file is concentrated where pages exposed either no live event calendar or only unlabeled month/day references that could not safely be turned into confirmed 2026–2027 ISO dates. I therefore prioritized honesty over false precision: many organic towns correctly remain `events: []`, with timing windows instead.

I genuinely live-researched **24 entries**, left **142** as `ambiguous` normalized records anchored to the directory plus whatever public anchor pages I could validate, and marked **9** as `not-found`; the thinnest evidence clusters were the BlissInvestor community pages, Worldschool Atlas pages that failed live capture, and a few Worldschooly listings whose session windows lacked explicit years.
